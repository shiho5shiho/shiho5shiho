| 成果物           | 分類        | 何を決めるためのものか                               |
| ---------------- | ----------- | ---------------------------------------------------- |
| ユースケース図   | UMLの図     | 誰が、このシステムで何をできるか                     |
| シーケンス図     | UMLの図     | 1つの処理が、どこからどこへ、どの順で流れるか        |
| 状態遷移図       | UMLの図     | 1件のデータの状態が、何をきっかけに移り変わるか      |
| クラス図         | UMLの図     | プログラムをどんなまとまりに分け、互いにどうつなぐか |
| 画面遷移図       | UML以外の図 | どの画面から、どの操作で、どの画面へ移るか           |
| ワイヤーフレーム | UML以外の図 | 1つの画面に、どの項目をどう並べるか                  |
| ER図             | UML以外の図 | どんなデータを、どんな関係で持つか                   |
| 権限マトリクス   | 表          | どの役割の人が、どの機能を使えるか                   |
| CRUD表           | 表          | どの機能が、どのデータを作り・読み・書き換え・消すか |

***💡 名前だけ知っておく図（今は覚えなくてOK）
- オブジェクト図: ある瞬間のデータの中身。クラス図の補助です。
- パッケージ図: まとまりどうしの依存関係。規模が大きくなると出番が来ます。
- コミュニケーション図: シーケンス図と同じやり取りを、誰と誰がつながっているかの側から表します。
- 配置図: プログラムがどのハードウェアの上で動き、どう通信するか。
- アクティビティ図: 作業の流れを、分岐や並行処理も含めて表します。
