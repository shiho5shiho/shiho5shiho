# when()の仕組み
when() は、「自分がコールバックを呼ぶときは、1番目にビルダ、2番目に値を渡す」という仕様

👇 when() の中で行われていること


```
->when( 条件 , 実行する処理 )
//      第1引数   第2引数
```
- 第1引数：真偽を判定される「条件」
- 第2引数：条件が真だったときに実行される「関数」

```
if ($value) {                   // ← 第1引数を条件として判定
    $callback($this, $value);   // ← 真なら第2引数の関数を実行し、その際に値を渡す
}
```
つまり第1引数は2つの役割を兼ねています。

1. 真偽の判定材料（実行するかどうかを決める）
2. 実行する場合に、関数へ渡される値

これが when() の便利なところで、「値があるかチェックして、あればその値を使う」という頻出パターンを1つにまとめてくれています。

```
$callback($this, $value);
//         │       └─ 材料（キーワードの文字列）
//         └─ 道具（クエリビルダ）
```
- $this = 加工する対象／道具（これに条件を書き足す）
- $value = 加工に使う材料（書き足す条件の中身）

```
function ($query, $keyword) {
//         道具    材料
    $query->where('title', 'like', "%{$keyword}%");
//   道具を使って ↑動作↑        材料を埋め込む
}
```

|要素|品詞的には|役割|
|---|---|---|
|$this / $query|名詞|条件を書き足される対象（クエリビルダ）=道具|
|$value / $keyword|名詞|書き足す条件に使う値（文字列）=材料|
|->where(...)|動詞|実際の動作|
