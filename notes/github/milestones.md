# GitHub Milestones

Milestone は Issue をグループ化して、目標単位で管理する機能。

---

## 主な用途

「いつまでに何を完成させるか」を管理する。

---

## イメージ

Milestone

Task Management App

│

├── Issue #1

├── Issue #2

├── Issue #3

└── Issue #4

---

## メリット

- 完了率が分かる
- 残タスクが分かる
- リリース単位で管理できる

## Projectsとの違い

| Projects                 | Milestones           |
| ------------------------ | -------------------- |
| タスクの現在地を管理する | ゴールを管理する     |
| 「今どこ？」             | 「何を完成させる？」 |
| カンバン方式             | 目標管理             |
