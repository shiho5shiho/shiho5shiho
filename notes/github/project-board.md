# GitHub Projects

GitHub Projects は、Issue や Pull Request をまとめて管理するためのタスクボード。

---

## 主な用途

- タスク管理
- 進捗管理
- Issueとの連携
- Pull Requestとの連携

---

## 基本構成

Todo
↓
In Progress
↓
Review
↓
Done

---

## カラム例

| カラム      | 内容           |
| ----------- | -------------- |
| Backlog     | まだ着手しない |
| Todo        | 次に着手する   |
| In Progress | 作業中         |
| Review      | レビュー待ち   |
| Done        | 完了           |

---

## おすすめ運用

Issueを作成
↓
Projectへ追加
↓
作業開始
↓
Pull Request作成
↓
Merge
↓
Doneへ移動

---

## メリット

- 進捗が見える
- Issueと連携できる
- Pull Requestも管理できる
- 個人開発でも抜け漏れを防げる

---

## 活用例

Todo
- タスクCRUD
- Category CRUD
- API
- Test

In Progress
- API実装

Review
- PR提出中

Done
- 認証機能

## Milestonesとの違い

| Projects                 | Milestones           |
| ------------------------ | -------------------- |
| タスクの現在地を管理する | ゴールを管理する     |
| 「今どこ？」             | 「何を完成させる？」 |
| カンバン方式             | 目標管理             |
