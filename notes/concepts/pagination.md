# ページネーション（デフォルト値、最小値、最大値）
役割分担
「デフォルト20件・最大100件」は、2箇所に分かれて実装されます。

|仕様|実装場所|実装内容|
|---|---|---|
|最小1件|BookIndexRequest|'per_page' => [..., 'min:100']|
|最大100件|BookIndexRequest|'per_page' => [..., 'max:100']|
|デフォルト20件|BookController::index|input('per_page', 20)|

分かれている理由：<br>
FormRequest は **「送られてきた値が正しいか」 を検証する場所であって、「送られてこなかった値を補う」場所ではない** からです。

per_page は nullable なので未指定でも検証を通過し、その後コントローラが「未指定なら20」と判断する、という流れになります。
